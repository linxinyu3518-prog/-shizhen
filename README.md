拾帧 · Media Extractor 1.4.1 粘贴视频网页或媒体直链，查看可获得的画质和时长，下载网站提供的原始媒体，或导出指定规格的视频、音频。界面在浏览器中运行，处理工作由本机 Python 与 FFmpeg 完成。  本项目自编写代码采用 GPL-3.0-or-later。服务层使用 Python 标准库；抖音通过独立的平台适配器、页面结构化数据和可选浏览器策略解析；其他网站可通过独立安装的 yt-dlp 适配器提供支持。媒体探测与编码通过本机 FFmpeg / ffprobe 独立进程完成。界面和业务流程没有复制其他下载器的实现。依赖及许可见 THIRD_PARTY_NOTICES.md。
