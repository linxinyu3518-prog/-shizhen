# 交付与验证记录

## 1.4.1 GPU 优先流式插帧（2026-09-17）

在 E 盘工作区用同一段本地生成的 1280×720、30 fps、4 秒、有 AAC 音轨素材执行 30→120 fps。CPU FFmpeg minterpolate + libx264（高质量）用时 59.127 秒，GPU CUDA RIFE 4.25 lite + NVENC（高质量）用时 13.438 秒，速度比约 4.40。重复一次 GPU 执行用时 12.415 秒。两种结果均为 480 帧、120 fps、4.0 秒视频，AAC 48 kHz，完整解码无错误。GPU worker 生成了 437 个真正中间帧，没有新增 PNG 临时帧；任务记录显示实际后端、编码器和时间。CPU 文件约 3.93 MB，GPU 文件约 10.34 MB；NVENC CQ 与 x264 CRF 档位不等价，速度比不能推断画质或压缩效率一样。

GPU 小样覆盖 30→60 MP4、30→120 AVI、60→120 MP4、120→60 AVI、30→120 快速转换，以及静止片段、切镜、无音轨、单帧极短视频。完整文件可解码，帧率、帧数、视频时长与目标相符。静止视频记录 0 个模型生成帧；切镜跨界记录 3 个被保留的画面，没有将它们误记为模型插值。音频解码存在 AAC 编码尾部填充，测试以视频时长和真实视频帧数验证片头片尾，不将容器总时长等同于视频时长。GPU 验收结果保存在 E 盘 `work/qa/gpu-stream-acceptance/results-gpu.json`；CPU 结果保存在同目录 `results-cpu.json`。这些时间是本机 RTX 5070 与该样本的实际值，其他素材、显卡、ComfyUI 并发和 AI 超分组合耗时需要各自实测。

真实浏览器选择 120 fps、流畅插帧和 GPU 优先，从示例解析到点击下载完成闭环。下载文件为 640×360、120 fps、960 帧、8.000 秒的 H.264 MP4，AAC 音轨为 48 kHz；完整解码无错误，任务卡显示 GPU RIFE / NVENC、生成 877 个中间帧和实测耗时。桌面 1440 像素与手机 390 像素宽度无横向溢出，浏览器无 JavaScript 运行错误。首次验收发现页面自动检测 AI 超分会占用共享 GPU 槽位，已改为用户选择 AI 或打开设置时才检测；重启后复测确认页面启动时 AI 探测请求为 0，选择 AI 时才发起探测，普通 GPU 任务总耗时 11.4 秒。360p 新增导出分别用 MP4、AVI 做完整解码检查；另对 720p→360p、30→120 fps 的 GPU 插帧实测获得 640×360、480 帧、4.000 秒、完整解码，GPU 处理耗时 5.939 秒。

自动测试 `python -m unittest discover -s tests -q`：213 项全部通过。前端 JavaScript 语法检查与 Python 编译检查通过。最终浏览器验收记录在 E 盘 `work/qa/gpu-stream-ui-results.json`；360p GPU 实测记录在 `work/qa/gpu-stream-acceptance/results-height360.json`。

最后一次重启后，本地 `127.0.0.1:8765` 报告版本 1.4.1，CUDA 插帧与 NVENC 编码均就绪；34 条历史任务可读，没有正在执行的任务。可移植源码包位于 E 盘 `outputs/拾帧-1.4.1-源码.zip`，包含 GPL 许可、源码、测试与文档；不包含 `.venv`、运行数据、个人配置、FFmpeg / NVIDIA 程序或模型权重。压缩包附有同目录 SHA-256 校验文件。

### 已知限制与后续冲突点

| 条件 | 可能表现 | 当前处理 / 后续验证 |
| --- | --- | --- |
| 首次启动外部 CUDA 模型或另有 ComfyUI 任务 | 等待 GPU、显存不足、首次处理慢 | 软件内 GPU 任务共用一个槽位；普通导出不再主动探测 AI。其他软件占用无法由本项目调度，需要在并发负载下复测 |
| 显卡驱动、PyTorch CUDA、NVENC 或模型版本变动 | 环境自检失败、权重形状不符、硬件编码器报错 | GPU 优先会说明实际回退路径；仅 GPU 明确失败。独立环境升级前保留原环境并跑实际小样 |
| 4K / 120 fps、长视频或高复杂度画面 | 显存/内存/磁盘压力及耗时上升 | 有任务帧数、时长、磁盘与无响应限制；目前未把短样片倍数推广为长片保证 |
| 极端可变帧率、损坏时间戳、HDR 或旋转标记 | 帧数或音画时间难以确定 | GPU 插帧拒绝不递增时间戳与 HDR / 旋转来源；更复杂的 VFR 与长片起始时间需代表性素材复测 |
| 快速运动、遮挡、切镜、闪光与字幕 | RIFE 中间帧可能扭曲或重影 | 已有静止与切镜小样；复杂真实场景仍需目视检验，可选择快速转换 |
| 只比较“高质量”档位的 NVENC 与 x264 | GPU 文件明显更大，画质也未必等价 | CQ 与 CRF 不是相同标尺；分别测文件大小、码率与主观效果，再调各自档位 |
| AVI 封装 H.264 / AAC | 某些播放器无声音或无法准确拖动 | 已验证编码与解码，兼容性优先选 MP4，目标播放器另行测试 |
| 非可信模型、插件或视频链接 | 外部 Python 模型代码执行风险、网络跳转访问不应访问的地址 | 仅加载可信来源的本地模型；本版仅绑定 127.0.0.1，不能直接作为公网多用户服务；需沙箱、鉴权及出口网络隔离后再部署 |
| 用户取消时外部进程异常退出 | 子进程残留或临时输出占磁盘 | 已有取消与清理测试，仍需在驱动崩溃、断电等系统级故障下复测；可检查本项目 `data/tmp` |
| 服务重启时任务尚未完成 | 任务变为失败，需手动重试 | 目前没有断点续传；重启前确认队列为空，历史结果与下载文件仍保留 |

上表区分了本次实测现象与需要后续场景复测的风险，不表示所有条目正在本机发生。

## 本次实现

沿用现有本地界面、Python 后端、下载队列、网站适配器和 FFmpeg，新增高保真编码与最高 120 fps 导出，不引入 AI 模型。

- 分辨率与压缩质量独立设置。当时的分辨率上限支持 480p、720p、1080p、1440p、2160p，默认保持来源尺寸；不放大低清来源，保持显示比例并使用偶数尺寸。360p 是在 1.4.1 补充的选项。
- H.264 编码质量：均衡 CRF 18 / medium、高质量 CRF 16 / slow（默认）、最高质量 CRF 14 / slow。
- 视频帧率可跟随来源，或指定 1–120 的整数。快速转换通过重复或丢帧保持播放速度；流畅插帧在提高帧率时使用运动补偿生成中间画面。
- 目标帧率不高于来源时直接转换；极短片段、来源时间信息不足时回退为快速转换，并在结果中说明。跟随来源的 MP4 保留可变帧率时间戳；AVI 规范化为来源平均帧率。
- 插帧前补足片尾参考画面，处理后裁回视频时间范围。保留音视频相对起始时间；AVI 同时处理 AAC 编码的负时间预滚包，避免整段画面被推迟。
- 每个任务分别记录用户设置、实际处理方式和导出后探测到的帧率、尺寸、编码、时长、文件大小。音频和原文件模式不应用视频编码设置。
- 运动补偿同时运行一个任务，等待和执行中的任务均可取消；保留超时、临时文件清理和旧任务记录兼容。运行环境显示插帧能力，缺少滤镜时保留快速转换。

视频输出为 H.264；转码音轨及音频导出为 AAC-LC、48,000 Hz、双声道、目标 256 kb/s。静音视频可导出为无声视频。

## 三档编码质量对比

同一份程序生成的 1 秒、640 × 360、30 fps 无损测试源，保持源帧率和尺寸，比较三个编码档位：

| 档位 | 与无损测试源的 SSIM | 文件大小 | 单次编码耗时 |
|---|---:|---:|---:|
| 均衡 | 0.998266 | 172,408 字节 | 0.368 秒 |
| 高质量 | 0.998827 | 188,062 字节 | 0.408 秒 |
| 最高质量 | 0.999180 | 208,927 字节 | 0.412 秒 |

该数据只描述这份合成素材的一次测量。SSIM 是结构相似度诊断指标，不代表所有真实视频的主观质量；短素材耗时也不代表长视频转码或插帧速度。更高质量档位不能恢复来源本来没有的细节。

从短 3840 × 2160 测试源另行导出并完整解码 2560 × 1440 / 120 fps 和 3840 × 2160 / 120 fps 文件，验证高分辨率输出路径。这是短片段快速转换验证，不是长视频 4K 插帧性能保证。

## 效果边界

检查了移动图案、文字、静止画面和快速切换画面。插帧确实生成中间帧，但在单帧白闪后立即切回的压力素材中观察到重影和局部文字变形。场景检测不能消除所有伪影；切镜密集、快速运动或遮挡较多的素材可选择快速转换。界面已说明两种模式的差异。

本次高保真升级作用于成功取得来源后的导出阶段。抖音 URL 规范化、独立平台解析器、用户主动登录的独立浏览器回退和内存 Cookie 导入已经保留，但仍受站点登录、网络及接口变化影响。此前作品 `7670847854776159515` 的匿名详情请求返回 403；本次没有用用户登录状态完成该作品的真实下载，因此不作该链接已恢复或所有平台均可用的承诺。

1.0.0 曾对 W3Schools 公开 HTML 视频示例完成实际解析、原文件下载、MP4 转码和音频提取；这一外网案例本次没有重复执行。本次新增验收使用自生成素材，不依赖平台素材或账号。
