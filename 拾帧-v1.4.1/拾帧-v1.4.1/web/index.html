    本地运行 / GPL-3.0-or-later / v1.0

    从链接到本地，三步就好。

    1. 粘贴并解析

      复制视频网页地址、媒体直链或分享文字，点击「解析链接」。读取成功后会显示标题、源画质、时长和编码信息。需要登录时，选择「浏览器解析」并在打开的独立浏览器中登录、播放目标视频；程序获取媒体信息后会自动返回，等待期间可取消。

    2. 选择保存方式

      「视频」转为 H.264 编码的 MP4 或 AVI；「音频」提取为 48,000 Hz、256 kbps 的 AAC 音频，优先使用兼容性较好的 M4A 封装。

    3. 提取并保存

      开始提取后可查看进度或取消。完成后点击「保存文件」，由浏览器下载到你的电脑。

    关于原文件与兼容性

    「原文件」尽量保留站点提供的媒体编码和封装，实际后缀由来源决定。H.264 输出会重新编码，不是逐字节相同的原文件。

    AVI 支持因播放器而异，H.264 + AAC 在 MP4 中通常有更好的兼容性。缺少音轨的源视频可导出无声视频，不能提取音频。

    网站支持范围取决于站点与解析器。浏览器解析使用独立会话，需要你自行登录或完成验证；无法提取受 DRM 保护的内容。仅处理你有权下载和使用的内容。
    LOCAL ENVIRONMENT

    本地运行环境

    解析与转码由这台电脑上的服务完成。

    Python 负责应用与任务管理，FFmpeg 负责媒体转换，yt-dlp 负责支持的网站解析。浏览器支持用于登录并读取目标视频。缺失依赖时，请根据项目说明安装后重启服务。
    SITE ACCESS

    抖音访问设置

    部分视频需要有效的抖音会话。可导入你从浏览器导出的 Netscape 格式 cookies.txt 文件，让本地程序使用该会话访问抖音。

    会话文件包含登录凭据，请只在本机选择，不要发送到聊天。有效会话也不能保证所有视频都能解析；导入后请回到工作台重新解析。
    LOCAL AI CONNECTION

    本地 AI 接口设置

    拾帧向本机 AI 服务提交画面，取回处理结果后导出视频。优先使用已就绪的 RTX 超分，或连接已有 ComfyUI。

    只连接本机地址：127.0.0.1、localhost 或 [::1]。请先启动你的 ComfyUI。

    点击「检测并保存」读取服务中的超分模型，再选择模型并保存。服务离线时也可保留地址与已有模型配置。

    RTX 显卡存在并不代表 RTX AI 超分已就绪；这里以实际超分接口检测结果为准。

    本次为拾帧主动调用的单向连接，不修改 ComfyUI 的 Python 环境，不自动下载模型。更大的目标尺寸会增加处理时间、显存和临时磁盘占用，模型效果因素材而异。
